# Model licences

No model files are shipped here. The TV body is built in code (`src/scene/materials/tv/`): extruded rounded
rectangles, a lathe for each knob, a lofted back shell and a domed glass grid. It is original work by the
technical-artist agent for this project, with no third-party mesh, scan or template. The project owner holds
the rights as for the rest of the repository.

Triangle count: 9,736 for the whole set (see `docs/handoffs/technical-artist.md`). Download size: 0 bytes.

## v2 rooms (added 2026-11-11)
The nine v2 rooms (`src/scene/materials/rooms/`) are also built in code: boxes, lofted ridges, silhouettes cut from
shapes, and shaders for sky, clouds, aurora, Earth, rain, steam and parallax. No model files, scans or third-party
meshes; original work for this project. Download size: 0 bytes. There is no `public/models/<room>/` folder because
nothing is shipped.
